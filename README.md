# LogiCore — Warehouse · Logistics · Enterprise

Демонстрационная корпоративная система, объединяющая **WMS + TMS + ERP** в одном интерфейсе на чистом HTML, CSS и Vanilla JavaScript.

## 🚀 Запуск

1. Скопируйте папку `LogiCore/` на диск.
2. Откройте `index.html` в браузере (двойной клик) — работает без сервера и сборки.
3. Нажмите «Войти в систему» → используйте один из демо-логинов:

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `1234` | Администратор (всё) |
| `manager` | `1234` | Менеджер (заказы, отчёты, поставщики) |
| `store` | `1234` | Кладовщик (склад, приёмка, отгрузка) |
| `logist` | `1234` | Логист (транспорт, рейсы, заказы) |
| `viewer` | `1234` | Наблюдатель (только чтение) |

## 📦 Возможности

- **WMS:** склады, ячейки, товары, остатки, приёмка, отгрузка, инвентаризация, перемещения.
- **TMS:** заказы со статусами, транспорт, водители, рейсы, обзор доставки.
- **ERP:** поставщики, финансы (доходы/расходы), сотрудники, отчёты.
- **Система:** роли и разрешения (демо), настройки, тёмная/светлая тема, экспорт/импорт JSON.

## 💾 Хранение данных

Все данные сохраняются в `localStorage` браузера под префиксом `logicore_`.
- Это **не** синхронизируется между устройствами.
- Для переноса используйте **Экспорт/Импорт JSON** (страница «Настройки» или кнопка на главной).
- Демо-данные создаются **один раз** при первом запуске (версия seed = 3).
- Полная очистка — кнопка «Очистить все данные» в настройках (с подтверждением).

## 🛠 Технологии

Только HTML5, CSS3, Vanilla JS (ES6+), `localStorage`, JSON. Без фреймворков, сборщиков и сервера.

## ⚠️ Ограничения

- Вход и роли — **демонстрационные**, не являются реальной защитой.
- Нет GPS-навигации и реальной синхронизации между устройствами.
- Финансы — внутренний учёт, **не** бухгалтерская система.
- Браузер может ограничивать размер `localStorage` (~5 МБ).
